This code repository is MIT licensed. That license covers only project-authored software in this directory.

The bundled `VLMEvalKit/` fork retains its upstream Apache-2.0 license in `VLMEvalKit/LICENSE`. Project-specific adapters added to that fork are distributed under the same repository terms without removing any upstream notices.

The companion dataset is a mixed-license collection. Its Real World partition includes source material from All-Angles-Bench, CAPTURe-real, GQA/Visual Genome, IKEA Manuals at Work, OmniSpatial, ReasonMap, SPair-71k, SpatiaLQA, SSI-Bench, Visual-Jigsaw, and VisualTrans.

Important restrictions include:

- OmniSpatial is published under CC BY-NC 4.0 and is restricted to non-commercial research.
- SPair-71k requires compliance with the original PASCAL VOC and Flickr image terms.
- Other sources require their stated attribution, license notices, and source-image terms.

Consult `LICENSE_DATA.md`, `ATTRIBUTION.md`, and `manifests/sources.tsv` in the dataset repository before use or redistribution. No third-party dataset is relicensed by this software repository.
