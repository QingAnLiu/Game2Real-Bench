# Figure Assets

The figures in this directory are web-rendered versions of author-created figures from the Game2Real-Bench manuscript.

- `construction_pipeline.png`: capability-guided task design, procedural generation and verification, and real-world curation. Unused page-layout whitespace was removed for README display.
- `capability_examples.png`: representative Toy Game and Real World examples across the four benchmark capabilities.

These files are documentation assets for this repository. The manuscript source and unpublished result figures are not included in the code release.
